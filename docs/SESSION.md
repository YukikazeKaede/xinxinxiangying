# 登录与会话

0.7.1 优化教务、第二课堂和校园卡的统一认证会话复用。学校会话有效时复用系统 WebView Cookie；会话过期或学校要求验证码、二次验证时，仍需用户完成认证。

## 认证与账号隔离

- 本机身份用于识别当前账号，不能证明学校会话有效。恢复功能依赖学校返回的认证结果。
- 认证流程去重；只有当前流程可以结束自己的认证状态，完成后回到原功能。
- 同账号认证保留有效 Cookie；明确退出、切换账号或学生类型、本机账号所有者变化时清理 Cookie。
- 断网、TLS 错误、403、5xx、解析失败和普通页面的密码框不会触发全局退出。401 最多触发一次自动重认证，避免循环。
- 勾选记住密码时使用 Android Keystore 加密保存，只在学校统一认证页复用。学校明确拒绝密码后停止复用；验证码由用户填写。
- 保存课表、成绩和第二课堂数据前核对当前账号，拒绝旧页面和旧账号的异步回调。

## 自动同步与第二课堂

登录后依次读取课表、成绩、考试安排、第二课堂学分。单项失败保留原有快照；第二课堂无法读取或取消时返回首页。学分页自动展开可见明细，避开链接和表单提交控件，并等待读取结果稳定。同源 iframe 和延迟出现的展开控件也在处理范围内。

第二课堂学分与活动先走学校 CAS 学工入口，入口 HTTP 错误时有限回退到目标页。切换账号、页面或结束同步时取消旧读取任务。

## 验证记录

发布前代码测试：7 组 Java 测试共 366 项断言、Node 测试汇总 10/10、全部 10 份 Android 仪器测试源码编译通过。独立测试包在模拟器上使用合成账号和拦截响应，第二课堂同步 34 项、活动与筛选 36 项，共 70 项通过。

这些离线测试验证代码路径，不能代替学校真实 CAS、学校页面结构和设备兼容性验证。正式版发布由维护者在测试通过后授权。

## 回滚

没有数据库 schema 迁移。出现问题时撤回相关源码提交，并用原签名、递增的 versionCode 发布修复版。已安装用户通常不能直接降级安装旧 APK。
