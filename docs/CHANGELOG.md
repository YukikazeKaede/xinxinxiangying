# 版本说明

## 0.7.5

- 更换为绿色背景的双心图标。
- 移除第二课堂学分与活动页面的防截屏保护；支付宝 SDK 支付界面保留其自带的防截屏保护，其余应用自有页面均允许截屏和录屏，系统最近任务也可能显示页面预览。请自行保管和分享这些图像。
- 截图测试直接检查页面默认允许截屏，不再临时清除或重新添加防截屏标志。
- 将截屏规则纳入后续版本规范和构建检查，持续保留支付界面的保护并允许其他自有页面与测试截屏。

## 0.7.4

- 校园卡改用学校正式统一认证入口，进入后可选择“卡充值”。
- 确认支付服务隐私说明后，通过支付宝官方 SDK 打开支付；返回时重新进入校园卡并清除旧支付页历史，充值结果请核对学校记录。
- 校园卡登录过期时提供重新打开入口，避免重新加载付款表单；取消、失败和过时回调不会自动重试充值。

## 0.7.3

- 新增宿舍电费页面，显示剩余电费或电量及更新时间，进入时自动更新，支持手动更新和切换寝室；更新失败保留上次结果。
- 校区和区域自动填写，楼栋、楼层、房间由用户选择，选完房间自动保存；修复两页查询超时、旧余额误用和异步结果无法保存的问题，读取结果时核对寝室。
- 保留学校官方充值入口并恢复寝室选项，充值金额与支付仍由用户在学校页面确认。
- 活动列表顶部的“所有活动”和“我的活动”在各自圆角矩形中居中并加粗显示。
- 课表、成绩、考试、第二课堂学分和加分记录统一同步，学校页面在后台加载，前台只显示当前任务；需要学校验证时显示验证页，完成后继续，单项失败不阻断后续读取。
- 工具页调整为两行三列，移除学分情况和学校账号宫格，将活动报名改为二课报名；按参考图重绘扫码框、日历、校园卡、电费小屋、绩点柱状图和票券六个图标。
- 新增加分记录：从学校服务大厅读取活动名称、创建时间和认定学分，自动翻页并读取各学年，支持分类展开与学年筛选。
- 读取不全或中断时保留原缓存；移除页面诊断导出，退出并清除数据时一并删除全部账号的加分记录，保留第二课堂页面防截屏保护。

## 0.7.2

- 工具页新增全部学期平均绩点和第二课堂累计学分；成绩按课程学分加权计算，正确计入零绩点课程。
- 第二课堂活动改用学校完整列表接口，保留历史活动与学校顺序，支持学年、学期、类型、状态筛选和搜索。
- 活动列表默认查询本学期，每次加载 10 条，下滑继续加载；新增“我的活动”，读取失败可重试并保留已有数据。
- 第二课堂学分类别改为独立卡片，显示已获与要求学分，默认展开子项并支持收起。
- 工具页改为双列统计卡和两行四列彩色功能宫格，统一圆角、留白与轻阴影；导航使用扳手图标，顶部校园全景照片保留日期、教学周和今日课程摘要。

## 0.7.1

- 优化统一认证会话复用，减少进入教务、第二课堂和校园卡时重复输入账号密码；需要重新认证时返回原功能，验证码和二次验证仍由用户完成。
- 修复同步后已记住的密码被误清除、同账号登录清除有效会话及重复弹出认证页面的问题；断网、证书错误和服务异常时保留本机身份与已有缓存。
- 登录后依次同步课表、成绩、考试安排和第二课堂学分；第二课堂无法读取或取消时保留已有数据并返回首页。
- 自动展开第二课堂学分明细，避免重复点击和误触链接、表单；改进学工入口回退与切换账号后的旧页面回调处理。
- 补齐活动类型筛选，切换板块时重置类型，并将“全部”固定显示。

## 0.7.0

- 新增第二课堂学分，显示累计学分和德育、劳育、美育、健康教育明细，支持展开子项及本机缓存。
- 新增第二课堂活动，支持学年、板块、类型、报名状态筛选和名称搜索；隐藏结束超过 31 天的活动。
- 可查看活动时间、地点、学分、描述与主办信息，并在应用内报名，显示学校返回的处理结果。
- 第二课堂数据按学生类型和账号隔离；切换账号后的旧读取结果不再保存，清除缓存只影响当前账号。报名结果不明时不会自动重复提交。
- 活动时间按上海时区判断；保留 0.6.12 的课表滑动、付款码预热、本地姓名与头像等功能。第二课堂两个页面保留防截屏保护。

## 0.6.12

- 修复 360dp 等窄屏周课表无法左右滑动切周的问题，保留表格横向浏览及边缘切周。
- 周课表改为整页跟手滑动，相邻周同步进入；松手吸附、短拖回弹，首末周提供阻尼。
- 支持快速轻扫及动画中重新按下接管；切周保留纵向滚动位置，顶部栏和底部导航保持固定。
- 上一周、下一周按钮使用相同翻页动画；窗口尺寸变化或离开页面时及时清理未完成的动画。

## 0.6.11

- 工具页校园插画区域显示上海时区日期、当前教学周和今日课程数量；调课、无课表、未设开学日期及学期外均有对应提示。
- 周课表与每日安排支持左右滑动切换教学周，保留切周按钮和窄屏表格的横向滚动。
- 优化本科生整学期课表读取，最多同时查询两周；会话过期时停止后续查询。
- 工具页在前台提前准备付款码页面资源；每次出示仍重新获取学校当前付款码，退出前台或切换账号后清理预加载状态。
