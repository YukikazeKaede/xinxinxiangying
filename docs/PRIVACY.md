# 隐私说明

## 本机保存的数据

| 数据 | 位置 | 说明 |
| --- | --- | --- |
| 课表、调课、学期设置 | 应用私有 SharedPreferences | 按学生类型与账号作用域隔离 |
| 成绩、考试、GPA 快照 | 应用私有 SharedPreferences | 只保存最近一次同步结果 |
| 第二课堂学分、活动列表 | 应用私有 SharedPreferences | 按学生类型和账号隔离，读取失败保留原有快照 |
| 学校账号 | 应用私有 SharedPreferences | 学号明文用于区分账号；密码默认不保存 |
| 姓名 | 应用私有 SharedPreferences | 从学校课表响应读取，按学生类型与账号隔离 |
| 自定义头像 | 应用私有文件目录 | 用户通过系统选图主动选择，缩小并重新编码后保存，不上传 |
| 记住的密码 | Android Keystore 加密后存本机 | 仅用户主动勾选时；退出/清除可删除 |
| WebView 登录 Cookie | 系统 WebView Cookie 存储 | 由学校会话有效期决定；退出时尝试清除 |
| 更新下载文件 | 应用私有目录 | 校验 SHA-256 后交给系统安装器 |

应用不包含统计 SDK、广告 SDK 或远程日志。除学校网站、学校接口和应用更新清单外，不主动发起网络请求。

学校统一认证会话由系统 WebView Cookie 维护；应用不复制、不拼接、不扩大 Cookie 作用域。只有明确退出、切换账号/学生类型或本机账号所有者变化时才清除；网络错误、证书错误、403、5xx 和普通页面里的密码框都不会触发清除。勾选记住密码后，只在学校统一认证页复用已保存账号，验证码或二次验证仍由用户完成。

进入工具页时，应用会在前台用现有会话向学校付款码页面预加载一次，预热连接和静态资源；不接管登录重定向，10 秒未完成则放弃，完成立即清空码文档。离开工具页取消预加载。校园付款码返回后也会清空页面文档，仅在同一账号、应用前台短时保留一个空白 WebView（最多 60 秒），以减少再次打开的初始化。再次出示重新加载学校官方页面，不保留二维码截图或旧码文档，不强制缓存动态码，不在后台轮询。账号失效/切换/退出、离开应用、内存紧张、超时或主页面加载失败时销毁该运行环境；原有学校 Cookie 仍按上表机制管理。

## 权限

平均绩点读取全部学期成绩并按课程学分加权计算，统计卡复用本机成绩与第二课堂学分快照；不新增权限、第三方服务或数据上传。

第二课堂学分和活动页面保留防截屏、防录屏保护；其他页面允许截屏和录屏，包括登录、教务数据和校园卡页面；系统最近任务也可能显示页面预览。请自行保管和分享这些图像。发布包关闭 WebView 调试和同步日志，不输出完整网页控制台消息或教务数据。

- `INTERNET`：访问学校网站与更新清单。
- `POST_NOTIFICATIONS`：课前提醒。
- `RECEIVE_BOOT_COMPLETED`：重启后恢复提醒。
- `REQUEST_INSTALL_PACKAGES`：应用内更新时调用系统安装器；实际安装仍需用户授权“安装未知应用”。

选择头像通过系统文件选择器读取单张图片，不申请相册或存储权限，不保留对原图的长期访问授权。电费页面仅自动选择“新电费缴纳 / 奉贤校区 / 住宿区”；楼栋、楼层、房间和后续缴费仍由用户操作。

## 网络与更新

- 更新清单必须是 HTTPS；下载完成后校验清单中的 SHA-256。
- 清单与 APK 地址由使用者在 `strings.xml` 的 `update_manifest_url` 配置；仓库默认值指向项目自己的 GitHub Releases。
- 应用不会上传设备信息、账号或成绩。

第二课堂活动详情临时保存在内存中。点击报名后，应用读取学校表单默认值并提交到学校第二课堂系统；只显示学校返回的处理结果，不在本机保存报名表单。“我的活动”通过学校只读查询读取已报名活动，作为活动列表缓存按账号保存在本机，不会自动报名或取消报名。同一次报名读取不会自动重复提交；结果不明时需返回详情刷新核对。学校时间统一按上海时区判断。

## 删除数据

- 应用内“退出登录”会清除本机账号授权、课表、成绩、考试、第二课堂学分与活动缓存、姓名、头像与网页登录状态；具体以当前版本为准。
- 卸载应用会删除应用私有目录；无法删除已经导出到公共目录的文件。

## 开源仓库注意事项

提交前请确认：

- 不包含 `.p12`、`.jks`、`keystore.properties`、`local.properties`；
- 不包含真实学号、姓名、成绩单、考试安排、Cookie、抓包日志；
- 不包含 `toolchain/`、`build/`、`dist/` 和带个人信息的截图；
- 测试使用合成账号与合成响应；
- 发布 APK 使用独立签名密钥，并备份私钥。

仓库中的 `_private/`、`analysis/`、`build/`、`dist/`、`toolchain/`、`signing/` 均被 `.gitignore` 排除；请勿用拖拽方式把这些目录上传到 GitHub 网页。
